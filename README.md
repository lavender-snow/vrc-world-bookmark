# VRChat World Bookmark

VRChatのワールドブックマークアプリです。
ワールド探索を補助するツールが欲しいと考え作成しました。

ゲーム内のワールドブックマーク機能は以下の課題を抱えていると考えており、本アプリはこれらの課題を解決します。

- ブックマーク数に上限が存在する
  - 100ワールド * 4カテゴリの400が上限
- ジャンル別の管理が難しい
  - 5つ以上の分類が出来ない
- ワールドの探索状況を管理出来ない
  - 行ったことがないワールドを中心にたくさん探索したいといった要求を満たせない
  - 行ったことがあるが、コンテンツを踏破したかどうかといったことも後から正確に把握出来ない
- メモ書きが出来ない
  - どういったワールドかという情報を保存出来ない
- 探索候補から提案をしてくれない
  - 探索候補のワールドからおすすめを1つ選んで提案してくれるといった機能がない

# 主な機能

- ワールド情報の登録
  - 自由入力の可能なメモ、タグ付け、訪問状況
- 登録したワールド情報から条件を指定した抽出
- ワールドおすすめ機能
  - 未探索のワールドからおすすめワールドを提案する機能
  - LLMと連携した対話ベースによるおすすめワールド提案機能
    - LLMを利用するためのアクセスキーはご自身で用意して頂く必要があります。
    - 現状Amazon Bedrockにのみ対応しています

データはPC上の`%APPDATA%\vrc-world-bookmark`配下に保存されます。

## インスタンス作成・招待

設定の「VRChat」でログインし、ワールドカードの「インスタンスを作成」から作成モーダルを開きます。公開範囲の初期値はInvite+、リージョンはJapanです。

作成後は自分、または一覧から選択したフレンドへ一人ずつ招待を送信できます。フレンド一覧はオンライン／オフラインを切り替え、ページ送りと表示中の名前検索ができます。招待に失敗しても作成結果は保持され、招待だけを再送できます。通信切断などで送信結果が不明な場合は、重複して届く可能性を確認してから再送します。

作成フォームの「作成後に自分を招待する」は初期状態でオンです。「マイインスタンス」タブでは、この起動中・ログイン中に作成したインスタンスを確認し、個別に招待を送れます。所有者本人と確認できたインスタンスは、確認操作を経てVRChat上で閉じることもできます。一覧はログアウトやアプリ終了でクリアされます。

「マイインスタンス → フレンドグループ」では、グループ名と複数のフレンドを登録・編集・削除できます。選択したメンバーはページ送りやオンライン／オフラインの切り替えでも保持されます。グループはアカウントごとにこのPCへ保存され、再起動後も利用できます（最大100グループ、各100人）。VRChat上のグループとは別の、アプリ内の招待先リストです。

作成済みモーダル、または「マイインスタンス」の招待画面では保存済みグループが自動で読み込まれ、対象ワールド・メンバーを確認してまとめて招待できます。グループが1件なら選択済みになり、複数ある場合は選択欄から直接選べます。送信は1人ずつ、次の送信まで1秒間隔を置いて行い、メンバーごとの送信済み・失敗・結果不明・未送信を表示します。画面を閉じても送信を継続し、「残りの招待を停止」で中止できます。送信制限や通信障害時は停止し、再操作ではこのインスタンスへの送信済みメンバーを除きます。結果不明の再送には確認チェックが必要です。ログアウトやアプリ終了では残りの送信を継続しません。招待の送信は、相手の受信・移動完了を保証するものではありません。

非公式APIを利用しています。作成後の自動自己招待の受信はユーザーによる確認済みですが、各公開範囲での入室・フレンド招待・閉鎖の実機動作は未検証です。

# 使い方

上部メニューは「おすすめ」「ワールド一覧」「マイインスタンス」「ワールド登録」「設定」の5項目です。ワールド情報の登録は「ワールド登録」タブから、「フレンドグループ」の管理はマイインスタンス内の切り替えから開けます。

1. [Release](https://github.com/lavender-snow/vrc-world-bookmark/releases)から最新バージョンのzipファイルをダウンロードし、展開します。
2. vrc-world-bookmark.exeを起動します。
3. ワールド情報登録にVRChatのワールドURLまたはワールドIDを貼り付け、`ワールド情報登録`ボタンを押下します。
4. 情報が登録され、ワールド一覧で管理されるようになります。

## 注意事項

本アプリはデジタル署名を行っていません。

そのため、Windowsなどで実行時に「発行元不明」等の警告が表示されますが仕様です。
気になる方はソースコードをご確認のうえ、ご利用ください。

# 開発環境構築クイックスタートガイド

Electron + React + SQLiteで構築されています。

## 前提条件

以下のツールを導入します。
- nodejs
  - v24.18.0 (Volta)

## プロジェクトクローン&依存モジュールインストール

```
git clone git@github.com:lavender-snow/vrc-world-bookmark.git
cd vrc-world-bookmark
```

## 実行

```
npm run dev
```

## exeファイル作成

electron-forgeを使用しパッケージ化します

```
npm run package
```

## zipファイル作成

electron-forgeを使用しzipファイルを直接作成します

```
npm run make
```
